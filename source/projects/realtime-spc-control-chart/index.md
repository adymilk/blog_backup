## 1. 项目背景

现代制造产线对过程质量的监控要求正从“事后抽检分析”转向“过程实时预警”。本项目围绕 Minitab 二次开发能力与前端可视化体系，构建面向产线质量工程的实时 SPC 控制图生成与监控方案。

- **所属领域**：智能制造 / SPC 与过程能力分析
- **客户背景**：[可编辑占位：例如 新能源汽车或精密制造质量监控场景]

## 2. 业务痛点

- **反馈滞后**：传统离线分析无法在工序发生趋势漂移或异常波动时第一时间告警。
- **可视化体验割裂**：桌面软件生成的静态图片难以满足产线看板、多维度下钻和实时刷新的交互需求。

## 3. 解决方案

结合工业统计分析内核与实时数据链路，实现产线质量数据自动采集、SPC 判异规则实时计算与 Web 端动态控制图渲染。

```text

```

## 5. 核心功能

- **实时控制图渲染**：支持动态刷新与异常点高亮标示。
- **过程能力分析（Cpk/Ppk）**：结合统计规则辅助质量工程师快速定位制程波动原因。
- **多端可视化展示**：适配质量看板大屏与工程人员 PC 端日常巡检。
