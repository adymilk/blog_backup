## 1. 项目背景

在传统工业软件与制造企业中，大量质量标准文档、历史异常处理经验与统计分析操作高度依赖资深工程师的隐性知识。随着大模型与 AI Agent 技术成熟，如何让 AI 安全、准确地接入工业分析工作流成为核心探索方向。

- **所属领域**：企业级 AI 应用 / AI Agent / 数据智能
- **项目定位**：产品原型与企业级落地架构探索

## 2. 业务痛点

- **专业工具门槛高**：一线业务人员难以熟练选择控制图类型、设置子组参数并解读复杂的统计判异结果。
- **知识检索低效**：设备SOP、历史质量问题复盘分散在各类文档中，缺少上下文关联。
- **通用大模型幻觉风险**：工业与质量场景对准确性要求极高，直接套壳问答无法通过企业级验收。

## 3. 解决方案

构建 **“意图识别 + 企业知识 RAG + MCP 工具调用 + Golden Set 评测闭环”** 的工业 AI Agent 架构：

- 将工业统计分析能力封装为标准化工具接口（Tool / MCP）。
- 引入 RAG 检索企业质量规范与历史案例，确保分析建议有据可依。
- 建立可回归的评测数据集（Golden Set），用客观准确率指标驱动提示词与工作流迭代。

## 4. 系统架构

```text
[自然语言质量查询]
        │
        ▼
[AI Agent 编排层] ◀──▶ [RAG 知识库（质量标准 / 历史复盘）]
        │
        ├──▶ [MCP Tool：SPC 参数生成与统计调用]
        └──▶ [结果解读与自动化评测集 (Golden Set Eval)]
```

## 5. 核心功能

- **自然语言转分析参数**：自动理解产线、指标与时间范围，生成规范的统计分析调用参数。
- **智能异常归因辅助**：结合统计结果与企业历史知识库给出结构化排查建议。
- **评测与可观测闭环**：[可编辑占位：例如 计划/已构建 N 条行业评测样本与回归报告]

- 企业级 AI 的核心壁垒不在于模型本身，而在于**对垂直行业工作流的深刻理解、工具边界控制以及严谨的评测体系**。
